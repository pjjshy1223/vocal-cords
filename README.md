# 인공 성대 (Vocal-cords)

목이 불편할 때, 미리 녹음해 둔 내 목소리를 버튼으로 재생하고, 즉석에서 입력한 문장은 음성합성(TTS)으로 읽어주는 보조 발성 PWA입니다. 갤럭시 Z 폴드7 등 안드로이드 폰에 "홈 화면에 추가"로 설치해 오프라인으로 씁니다. (앱 표시 이름: **인공 성대** / 저장소·코드 이름: `vocal-cords`)

## 기능
- 음성 버튼을 직접 만들고 이름 지정 → 앱 안에서 바로 녹음
- 버튼 탭하면 재생, 재녹음/이름변경/삭제 가능
- 전체 볼륨 증폭(100~400%) + 버튼별 개별 증폭 (녹음한 소리보다 크게 출력)
- 자주 쓰는 버튼 ★고정 → 항상 맨 위, 순서 이동
- 🗣️ "직접 입력" 타일: 문장 입력 → 한국어 TTS로 읽어줌, 최근 문장 재사용
- 다크/라이트 테마, 모든 데이터(녹음·설정)는 폰 안에만 저장(IndexedDB/localStorage)
- 서비스워커로 오프라인 동작

## 로컬에서 실행/테스트
HTTPS 또는 `localhost`에서만 마이크 녹음·서비스워커가 동작합니다.

```bash
# 아무거나 하나
python -m http.server 8000
npx serve .
```
→ 브라우저에서 `http://localhost:8000` 접속.

## GitHub Pages 배포 (서버 안 켜둬도 됨)
1. 이 폴더를 **공개(public)** GitHub 저장소로 푸시
2. 저장소 **Settings → Pages → Build and deployment → Source: "Deploy from a branch"**, 브랜치 `main` / 폴더 `/ (root)` 선택 후 저장
3. 잠시 후 `https://<사용자명>.github.io/<저장소명>/` 주소가 생성됨
4. 폰 Chrome에서 그 주소 접속 → 메뉴 **⋮ → 홈 화면에 추가** (또는 "앱 설치")
5. 이후엔 홈 화면 아이콘으로 실행. 인터넷 없이도 동작 (TTS는 폰의 시스템 음성 사용 — 보통 온디바이스라 오프라인 OK; 한국어 음성이 없으면 안드로이드 설정 > 접근성 > TTS 출력에서 설치)

> 비공개 저장소에서 Pages를 쓰려면 GitHub Pro가 필요합니다. 공개 저장소로 두면 코드만 공개될 뿐, 녹음한 음성은 폰에만 저장되어 외부에 노출되지 않습니다.

## 파일 구성
- `index.html` — 앱 셸 / 마크업
- `styles.css` — 디자인 토큰, 레이아웃, 시트/슬라이더 스타일
- `app.js` — IndexedDB, 녹음, Web Audio 재생+증폭, TTS, 편집 UI
- `sw.js` — 서비스워커 (앱 셸 캐시, 오프라인)
- `manifest.webmanifest`, `icons/` — PWA 설치 메타데이터/아이콘
